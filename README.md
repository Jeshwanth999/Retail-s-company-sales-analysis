# Retail-s-company-sales-analysis
This repository contains a complete, industry-standard, end-to-end data analytics workflow designed to mirror the daily responsibilities of professional data analysts in modern business environments. cycle—ranging from data preparation and relational modeling to advanced insight generation, interactive visualization, and reporting.   
   
# 📌 Project Overview
The objective of this project is to transform raw retail transaction data into a robust business intelligence dashboard using an end-to-end stack (Python $\rightarrow$ SQL $\rightarrow$ Power BI).


# KPIs 
Total Number of Customers <br>
Average Purchase Amount<br>
Average Review Rating.  <br> 

# 📈 Key Dashboard Metrics & Visualizations (as seen in the preview):<br>
1)Summary Cards: Highlights core KPIs including Total Number of Customers, Average Purchase Amount, and Average Review Rating.   <br>
2)Interactive Slicers & Filters: Filter data dynamically by Subscription Status, Gender, and Location (States from Alabama to Florida).<br>  
3)Category Breakdown: Bar chart visualizing Average Purchases by Category (Clothing, Accessories, Footwear, Outerwear).   <br>
4)Customer Subscription Insights: A donut chart showing the Count of Customers By Subscription.<br>

5)Seasonal Payment Trends: Grouped bar charts tracking Customer By Season-wise Pay Method (Bank Transfer, Cash, Credit Card, Debit Card, PayPal, Venmo) across Summer, Fall, Winter, and Spring.<br>
6)Purchase Frequency Trends: Area chart tracking Customers Periodically Purchases ranging from Annually down to Fortnightly.   <br>
# 🛠️ Project Architecture & Workflow<br>
1)Data Preparation & Cleaning (Python): Import raw datasets, handle missing values, and perform exploratory data analysis using Jupyter Notebooks.<br>
2)Database Management (SQL): Load the cleaned data into a relational database to simulate transactions and execute complex business queries.<br>
3)Data Visualization (Power BI): Connect the database to Power BI to design an executive-ready, interactive analytical dashboard (as showcased above). <br> 
4)Insights & Reporting: Document key findings and strategic retail recommendations.<br>
